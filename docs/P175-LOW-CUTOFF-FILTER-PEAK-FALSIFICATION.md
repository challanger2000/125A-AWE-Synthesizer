# P175 — independent EMU8000 dark-filter envelope falsification

**NO-GO until independent Windows and owner-host acceptance.** This is a narrowly scoped fix for a newly discovered P170 bug, not the FULL AUDIT or a ROM/SF2 hardware-parity claim.

## Trigger and defect (actual PCM, not UI source inference)

Original source was pinned to `b02e02d472544eb2122533f9b8d7dc9d0b97f68a`, with the 125A standalone `awe32_p170_audio_render` and **actual 86Box EMU8000 PCM renderer** built using GCC 14.2 C++23. A privately supplied 1 MiB EMU8000 ROM was used locally; **NO private ROM, SoundFont, PCM sample bytes, or source bank has been uploaded**. The test SF2 is instead a publicly reproducible synthetic file generated by `tests/p170_audio_oracles.py` from three harmonics and deterministic SoundFont generator values.

At initial filter generator `initialFilterFc=6000` (SF2 cents, IFATN cutoff register=56), enabling the automatic filter envelope without any SF2 PEFE route produced:
- Initial patch: upper harmonic (17th, 0.035–0.1 s) **0.00008764** normalized.
- P170 at full filter ADSR: upper harmonic **0.00147786**, **16.86× the unchanged source**, not an envelope whose peak is at the original cutoff.
- At `initialFilterFc=4000` (hardware floor), the same accidental brightening was **77×**.
- The retained patch was otherwise correctly dark at 0% overlay.

**Root cause:** `Synth::StartLayers` selected `PEFE.lo=round(96*overlay)` (up to 6 octaves), subtracted `2*PEFE.lo` from a lower `IFATN.cutoff`, then clipped the IFATN base at zero. The positive PEFE modulation continued *unclipped*, exceeding the original patch's cutoff by multiple octaves. The previous P170 tests only exercised a high filter base (SF2 cutoff 13500), so their expected spectrum still closed and they could not reject this regression.

## Local minimal candidate (isolated branch)

Cap the newly synthesized PEFE filter depth by the available positive IFATN headroom: `depth=min(round(96*overlay),originalCutoff/2)`. Then compute compensated base as `originalCutoff-2*depth` without clipping. Existing positive/negative patch-owned PEFE routes and pitch bits are unchanged. The default 0% overlay, V11 state, MIDI, voice allocation, SoundFont parsing, real 86Box chip code, GUI and all original asset paths are unchanged. On patches already at zero cutoff, no positive PEFE depth is possible without violating the original-peak constraint; this limitation is intentional and not marketed as a filter-sweep PASS at the hardware floor.

**Same real 86Box PCM after the local change:**
- `initialFilterFc=4000`: filter depth0, edited 17th harmonic **0.00001912**, equal to neutral.
- `initialFilterFc=6000`: filter depth28, edited 17th harmonic **0.0000480**, **0.55×** neutral (but still greater than late-envelope harmonic ~0.0000159).
- `initialFilterFc=8000`: depth62, edited 17th harmonic **0.0002300**, **0.22×** neutral.
- For `initialFilterFc=12000/13500` and their un-clipped original IFATN headroom, filter route and audio were **unchanged** by the candidate.

## Falsifiable regression

Permanent check is inside the existing *real PCM* `tests/p170_audio_oracles.py` CTest, for low-cutoff synthetic SF2 values 4000, 6000, 8000. Assert independently measured 17th harmonic in the overlay is no greater than the unchanged patch's 17th harmonic plus stated tolerances; also assert the low-but-not-minimum cutoff has a genuinely audible declining harmonic envelope and nonzero positive PEFE depth. The original P170 source fails these new conditions (as independently demonstrated using the same 32-case native PCM sweep), not merely an API value check. Local patched test `ctest -R ^125A_p170_pcm_audio_oracles$` **1/1 PASS (23.69 s)**, new cases included.

This test was built from an exported archive of the **unchanged exact public source** pinned at `b02e02d`, taken by `git archive` in [P174 GitHub source snapshot #42484085027](https://github.com/challanger2000/125A-AWE-Synthesizer/actions/runs/42484085027). The original private SoundFonts and ROM remain local; all synthetic CTest audio is ephemeral.
